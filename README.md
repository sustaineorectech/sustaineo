# Sustaineo Website

Static website for Sustaineo Recycling Technologies Private Limited.

## GitHub Pages Deployment

1. Upload all files in this folder to the GitHub repository.
2. In GitHub, open `Settings` > `Pages`.
3. Select the deployment branch, usually `main`, and the root folder.
4. Configure the custom domain as `sustaineotech.com` in GitHub Pages and add the required DNS records with your domain provider.
